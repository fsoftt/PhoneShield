# Is your number shown wrongly?

You do not need an account or the app. You only need to prove the number is yours with a code we send by SMS.

## What you can ask for

- **Hide the names linked to your number.** Applied right away. Hiding names does **not** change whether a number is
  marked as spam, so nobody can use it to clean a spam number.
- **"My number is not spam".** A person reviews every request and answers within the deadlines of Colombian law
  (inquiries within 10 business days, complaints within 15 business days).

Each number gets **one SMS and one request per month**. This keeps the service free and stops anyone from using the
form to send messages to numbers that are not theirs.

## What we do with your data

- The number is not stored: as everywhere in Tranqui, we only keep its hash with a secret key.
- The code is sent by Firebase (Google), which processes the number to deliver the SMS. As soon as you confirm the code,
  we delete the session Firebase creates to verify it.
- If you leave an email, we use it only to answer and delete it once the request is resolved.
