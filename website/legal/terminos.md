# Términos y condiciones

::: warning Borrador
Este documento es un borrador pendiente de revisión legal.
:::

**Versión:** 2026-10-03

## 1. El servicio

Tranqui identifica llamadas y ayuda a bloquear spam usando información aportada por la comunidad. Es gratuito y de código abierto (AGPL-3.0).

## 2. Requisitos

Debes ser mayor de 18 años, o contar con la autorización de tus representantes legales.

## 3. Uso aceptable

No puedes:

- reportar números como spam a sabiendas de que no lo son, ni coordinar reportes falsos;
- usar Tranqui para acosar o identificar a personas;
- intentar extraer datos de forma masiva o automatizada;
- usar etiquetas ofensivas o que contengan datos personales de otros.

Podemos limitar o cerrar cuentas que incumplan estas reglas.

## 4. Información de la comunidad

Los nombres y el marcado como spam provienen de lo que aportan otros usuarios. Hacemos lo posible para que sean
correctos, pero pueden equivocarse. Si tu número aparece mal, [pide una revisión](/guia/apelacion).

## 5. Disponibilidad

El servicio se ofrece "tal como está". Si no hay conexión o el servicio no responde, las llamadas suenan normalmente.

## 6. Privacidad

El tratamiento de datos se rige por la [Política de tratamiento de datos](/legal/politica-de-tratamiento).
